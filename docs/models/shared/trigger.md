# Trigger

The type of trigger method: link click or QR scan

## Example Usage

```ruby
require "dub"

value = Trigger::QR
```


## Values

| Name       | Value      |
| ---------- | ---------- |
| `QR`       | qr         |
| `LINK`     | link       |
| `PAGEVIEW` | pageview   |
| `DEEPLINK` | deeplink   |
