# CommissionCreatedEventType

The type of commission. Can be `click`, `lead`, `sale`, `referral`, or `custom`.

## Example Usage

```ruby
require "dub"

value = CommissionCreatedEventType::CLICK
```


## Values

| Name       | Value      |
| ---------- | ---------- |
| `CLICK`    | click      |
| `LEAD`     | lead       |
| `SALE`     | sale       |
| `REFERRAL` | referral   |
| `CUSTOM`   | custom     |
