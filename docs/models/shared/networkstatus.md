# NetworkStatus

The partner's network status on Dub.

## Example Usage

```ruby
require "dub"

value = NetworkStatus::DRAFT
```


## Values

| Name        | Value       |
| ----------- | ----------- |
| `DRAFT`     | draft       |
| `SUBMITTED` | submitted   |
| `APPROVED`  | approved    |
| `REJECTED`  | rejected    |
| `TRUSTED`   | trusted     |
