# Event

The type of event to retrieve analytics for. Defaults to `clicks`.

## Example Usage

```ruby
require "dub"

value = Event::CLICKS
```


## Values

| Name        | Value       |
| ----------- | ----------- |
| `CLICKS`    | clicks      |
| `LEADS`     | leads       |
| `SALES`     | sales       |
| `COMPOSITE` | composite   |
