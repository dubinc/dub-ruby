# ListPartnersRejectionReason

Preset reason when the application was rejected.

## Example Usage

```ruby
require "dub"

value = ListPartnersRejectionReason::NEEDS_MORE_DETAIL
```


## Values

| Name                         | Value                        |
| ---------------------------- | ---------------------------- |
| `NEEDS_MORE_DETAIL`          | needsMoreDetail              |
| `DOES_NOT_MEET_REQUIREMENTS` | doesNotMeetRequirements      |
| `NOT_THE_RIGHT_FIT`          | notTheRightFit               |
| `OTHER`                      | other                        |
